# Subgen

Subgen refreshes Plex and Jellyfin after saving each video subtitle, including
subtitles generated by Web UI and agent/API batches.

## Configuration

Copy `subgen-secrets.env.template` to the gitignored `subgen-secrets.env` on first
setup and populate the required credentials. Set `JELLYFIN_TOKEN` to a dedicated
Jellyfin API key from **Dashboard -> API Keys**. The Deployment supplies
`JELLYFIN_SERVER` using the internal Jellyfin Service.

Plex uses the existing `PLEX_SERVER` and `PLEX_TOKEN` configuration. All three
containers see the same underlying media at `/tv`, `/movies`, and `/music`, so no
per-server path mapping is needed. If mount paths change, configure both
`JELLYFIN_PATH_MAPPING_FROM` and `JELLYFIN_PATH_MAPPING_TO` (and the corresponding
Plex pair) from the Subgen-visible root to the server-visible root.

Webhooks are not required for post-save refresh. To additionally trigger subtitle
generation from Jellyfin events, configure its optional Webhook plugin to send
JSON to `/webhook/jellyfin` and enable the corresponding Subgen processing flags.

## Temporary uploads

`TMPDIR=/transcode` directs Python temporary files, including Starlette multipart
uploads that exceed its 1 MiB in-memory spool threshold, to the existing
disk-backed `emptyDir`. Audio extraction already uses `/transcode`. This avoids
upload failures on the read-only root filesystem without adding a memory-backed
`/tmp` volume that would count large uploads against the container's memory limit.
The volume is ephemeral and must have sufficient node disk space for concurrent
uploads and extractions.

## Deploy and verify

After merging manifest changes:

```bash
kubectl apply --dry-run=server -k kubernetes/mediaplayback/subgen/
kubectl apply -k kubernetes/mediaplayback/subgen/
kubectl rollout restart deployment/subgen -n mediaplayback
kubectl rollout status deployment/subgen -n mediaplayback
```

The restart reloads credentials from the fixed-name Secret and pulls `latest`
because `imagePullPolicy` is `Always`. Avoid restarting during active batches.
Reload the Web UI to check the Plex/Jellyfin connection badges, or inspect
`GET /api/status`. Connected confirms authenticated read access; individual
refresh results report whether a subtitle refresh was queued, not whether
Jellyfin has finished indexing it.
